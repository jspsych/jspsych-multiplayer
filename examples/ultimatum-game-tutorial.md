# Tutorial: Building a Two-Player Ultimatum Game with jsPsych Multiplayer

This tutorial now lives on the documentation site:
[Building a two-player ultimatum game](https://multiplayer.jspsych.org/tutorials/ultimatum-game).
Its source is [`docs/docs/tutorials/ultimatum-game.mdx`](../docs/docs/tutorials/ultimatum-game.mdx).

The finished experiment is [`ultimatum-game-local.html`](./ultimatum-game-local.html), which runs in
two browser tabs with no server. [`ultimatum-game-jatos.html`](./ultimatum-game-jatos.html) and
[`ultimatum-game-firebase.html`](./ultimatum-game-firebase.html) run the same game on real backends.
